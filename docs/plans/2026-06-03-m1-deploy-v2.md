# M1 部署 v2 — 香港轻量服务器 + Caddy + Docker Compose

> Date: 2026-06-03
> Prereq: M1 代码（commit `bbb1281`）已完成，本地 docker postgres 跑得起来。
> Replaces: `docs/plans/2026-06-03-m1-deploy.md` (v1 撤回，over-engineered)

**Goal**：4-5 小时内把 M1 系统挂上 `https://app.<your-domain>` 供客户演示。3 人轻量私用，1 台服务器全栈。

**Architecture**：
```
Client browser
     │
     ▼  HTTPS + Basic Auth
┌─────────────────┐
│  阿里云香港轻量  │   2c4G ~¥80/月
│  服务器          │
│                  │
│  ┌────────────┐  │
│  │   Caddy    │  │  443 → 自动 LE 证书 + basic auth
│  │            │  │  internal: frontend
│  └─────┬──────┘  │
│        │ docker network
│  ┌─────┴──────┐  │
│  │  frontend  │  │  Next.js standalone :3000
│  │  /api/back │──┼──── rewrite ───┐
│  └────────────┘  │                │
│                  │                ▼
│                  │   ┌────────────┐
│                  │   │  backend   │  FastAPI :8088
│                  │   └─────┬──────┘
│                  │         │
│                  │   ┌─────┴──────┐
│                  │   │  postgres  │  pgvector :5432, volume
│                  │   └────────────┘
│                  │
│   volume: pg_data, uploads
└──────────────────┘
```

**Tech Stack**：阿里云香港轻量服务器（2c4G Ubuntu 22.04）/ Docker Compose v2 / Caddy 2 / pgvector/pgvector:pg16（容器）/ 现有 backend + frontend

---

## 设计决定（已定，不再问）

1. **PG 在容器内**（不用 RDS）：volume 持久化 + 每日 pg_dump
2. **uploads 用 docker volume**（不用 OSS）：演示数据量小
3. **Caddy 边缘鉴权**（不在 FastAPI 加 middleware）：单层 basicauth 在 Caddy，backend 不公网暴露
4. **frontend 内部反代 backend**（Next.js rewrites）：浏览器只看到 frontend 域名，backend 全程内网
5. **不做 CI/CD**：`git pull && docker compose up -d --build` 一行 alias
6. **不做 ACR**：服务器直接 build 镜像
7. **演示加品牌包装**：favicon + 标题 + 首页 1 段说明 + 失败兜底文案

```caddy
  }

  reverse_proxy frontend:3000 {
    header_up Host {host}
    header_up X-Real-IP {remote_host}
  }

  log {
    output stdout

  }
}
```

## Task 10: 备份 + 监控 + runbook（我，30 分钟）

### 10a. 每日 pg_dump（cron）

**Files**: `deploy/backup.sh`

```bash
#!/usr/bin/env bash
set -euo pipefail

BACKUP_DIR=/opt/rag/backups
DATE=$(date +%Y%m%d_%H%M%S)
mkdir -p "$BACKUP_DIR"

# PG dump
docker exec rag_pg pg_dump -U raguser -d ragdb \
  | gzip > "$BACKUP_DIR/pg_$DATE.sql.gz"

# uploads tarball
docker run --rm -v rag_uploads:/u alpine \
  tar czf - -C /u . > "$BACKUP_DIR/uploads_$DATE.tar.gz"

# 保留最近 7 天
find "$BACKUP_DIR" -name "pg_*.sql.gz" -mtime +7 -delete
find "$BACKUP_DIR" -name "uploads_*.tar.gz" -mtime +7 -delete

echo "[$(date)] backup done: $DATE"
```

部署：
```bash
chmod +x /opt/rag/deploy/backup.sh
# 加 cron
(crontab -l 2>/dev/null; echo "0 4 * * * /opt/rag/deploy/backup.sh >> /opt/rag/backups/cron.log 2>&1") | crontab -
```
