# M1 部署到阿里云香港 SAE — Implementation Plan

> Date: 2026-06-03
> Prereq: M1 代码完成（commit `bbb1281`），单元测试 7/7，本地 docker compose 跑得起来。
> Scope: 把 M1 系统部署到公网，3 人小团队可访问，能传企业内部 PDF 问答。

**Goal**：4-5 天内把当前本地能跑的 RAG 系统挂到 `https://<your-domain>` 上，3 人 basic auth 私用，PDF 持久化到 OSS，DB 用阿里云 RDS。

**Architecture**：
- 前端 Next.js → 阿里云 SAE（容器化）
- 后端 FastAPI → 阿里云 SAE（容器化）
- DB → 阿里云 RDS for PostgreSQL 14+（启用 pgvector 扩展）
- 文件存储 → 阿里云 OSS（uploads/ 改造）
- 镜像仓库 → 阿里云 ACR（容器镜像服务）
- 入口 → 阿里云 SLB + Let's Encrypt 证书（或阿里云免费证书）
- 鉴权 → FastAPI middleware + 共享密码

**Tech Stack**：阿里云 SAE / RDS PG / OSS / ACR / SLB；不变：Python 3.12 / FastAPI / Next.js 14 / Docker

- [ ] **Step 3: 写 storage_service.py（统一接口，本地/OSS 双后端）**

```python
from __future__ import annotations
from pathlib import Path
from functools import lru_cache

import oss2
from app.config import get_settings


class _LocalStorage:
    def __init__(self, base_dir: Path):
        self.base = base_dir
        self.base.mkdir(parents=True, exist_ok=True)

    def put(self, key: str, content: bytes) -> str:
        p = self.base / key
        p.write_bytes(content)
        return str(p)

    def get(self, key: str) -> bytes:
        return (self.base / key).read_bytes()


class _OSSStorage:
    def __init__(self, endpoint: str, bucket: str, ak: str, sk: str):
        auth = oss2.Auth(ak, sk)
        self.bucket = oss2.Bucket(auth, endpoint, bucket)

    def put(self, key: str, content: bytes) -> str:
        self.bucket.put_object(key, content)
        return f"oss://{self.bucket.bucket_name}/{key}"

    def get(self, key: str) -> bytes:
        return self.bucket.get_object(key).read()


@lru_cache
def get_storage():
    s = get_settings()
    if s.use_oss:
        return _OSSStorage(
            s.oss_endpoint, s.oss_bucket,
            s.oss_access_key_id, s.oss_access_key_secret,
        )
    return _LocalStorage(s.upload_dir)
```


- [ ] **Step 2: 写 middleware/auth.py**

```python
import secrets
from base64 import b64decode

from fastapi import Request, Response
from fastapi.responses import JSONResponse
from starlette.middleware.base import BaseHTTPMiddleware

from app.config import get_settings


_PUBLIC_PATHS = {"/api/v1/health", "/api/v1/health/live", "/"}


class BasicAuthMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next) -> Response:
        settings = get_settings()
        if not settings.auth_password:
            return await call_next(request)
        if request.url.path in _PUBLIC_PATHS:
            return await call_next(request)

        header = request.headers.get("authorization", "")
        if header.startswith("Basic "):
            try:
                decoded = b64decode(header[6:]).decode()
                _, pwd = decoded.split(":", 1)
                if secrets.compare_digest(pwd, settings.auth_password):
                    return await call_next(request)
            except Exception:
                pass

        return JSONResponse(
            status_code=401,
            content={"detail": "auth required"},
            headers={"WWW-Authenticate": 'Basic realm="rag-mvp"'},
        )
```
